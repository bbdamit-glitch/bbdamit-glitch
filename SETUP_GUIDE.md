## 📌 How GitHub Special Profile Repositories Work

When you create a public GitHub repository with a name that **exactly matches your GitHub username**, GitHub treats it as a **special repository**. The `README.md` inside this repository is rendered directly on your main GitHub profile page (`https://github.com/<your-username>`).

> Example: If your GitHub username is `amitsharma`, your special repository must be named `amitsharma`.

### Step 2: Create Your Special Repository on GitHub

1. Open your browser and go to: **[https://github.com/new](https://github.com/new)**
2. In the **Repository name** field, type your **exact GitHub username**.
   - GitHub will display a special banner saying: *"You found a secret! `<username>/<username>` is a ✨special✨ repository that you can use to add a README.md to your GitHub profile."*
3. Make sure the repository visibility is set to **Public** (required for it to show on your profile).
4. Leave *"Initialize this repository with a README"* **unchecked** (we already created your complete README!).
5. Click **Create repository**.
